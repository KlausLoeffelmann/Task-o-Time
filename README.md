# Task-o-Time

A spin-off of a Legacy App my Germany company 'ActiveDevelop' once maintained and deployed at industrial customers from 2010 to 2016.
It's no longer maintained and out of support for a long time, but still serves it purpose - if not for its original intendent purpose, then as a perfect test candidate for staged (alright) but real life scenarios for testing modern LLM/Agent Software Migration and Modernization abilities.
